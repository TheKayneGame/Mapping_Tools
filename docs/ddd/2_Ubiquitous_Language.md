# Ubiquitous Language

The table below collects domain terms and definitions extracted from the memory bank.

| Term | Definition | Context | Example |
|---|---|---|---|
| Beatmap | In-memory and file representation of an .osu beatmap, containing hit objects, timing, metadata | Beatmap Editing / Persistence | Beatmap loaded via [`Classes/BeatmapHelper/Beatmap.cs`](Mapping_Tools/Classes/BeatmapHelper/Beatmap.cs:1) |
| HitObject | Individual time-positioned object (circle/slider/spinner) inside a beatmap | Beatmap Editing | [`Classes/BeatmapHelper/HitObject.cs`](Mapping_Tools/Classes/BeatmapHelper/HitObject.cs:1) |
| TimingPoint | A timing control point (redline/greenline) that defines BPM or SV multipliers | Beatmap Editing / Timing | [`Classes/BeatmapHelper/TimingPoint.cs`](Mapping_Tools/Classes/BeatmapHelper/TimingPoint.cs:1) |
| Timing | Domain service for efficient timing lookups and calculations | Beatmap Editing | `Timing.GetRedlineAtTime()` (binary search) |
| BeatmapEditor | Repository-like service that provides CRUD operations for beatmaps and file save/load | Persistence / Editor Integration | `BeatmapEditor.SaveFile()` |
| EditorReader | External integration layer that reads osu! editor memory state | Integration | `lib/EditorReader.dll` |
| EditorReaderLock | Synchronization primitive for safe editor reads | Integration / Threading | Used around memory reads to avoid races |
| BackupManager | Component responsible for creating timestamped backups before destructive operations | Safety / Persistence | `BackupManager.SaveMapBackup()` |
| Project | Tool/project configuration and saved tool state (ISavable) | Project / Persistence | `ProjectManager` saves per-tool projects |
| Sample | Audio sample metadata used by hitsound tools | Hitsound Management | Referenced by `HitsoundStudio` export |
| HitsoundLayer | Layered hitsound representation used to merge/export samples | Hitsound Management | `HitsoundLayer` objects merged by converter |
| Slider | Path-based hit object using anchors and curve math | Slider Tools | Generated by `Sliderator` / `SliderPicturator` |
| Pattern | Reusable mapping pattern stored in Pattern Gallery | Pattern Management | `PatternGallery/OsuPattern.cs` |
| SnappingGenerator | Geometry generator producing relevant objects (points, lines, circles) for snapping tools | Geometry / Snapping | `SnappingTools/DataStructure/RelevantObjectGenerators/Generators/` |
| ComboColourProject | Color timeline and combo color interpolation project | Visuals / Combo Colour | `ComboColourProject` |
| TumourGenerator | Algorithmic pattern generator producing complex patterns | Pattern Generation | `TumourGenerating/TumourGenerator.cs` |
| MappingTool | Base view for tools (workflow template, background worker hook) | Presentation / Tool Framework | `Views/MappingTool.cs` |
| BackgroundWorker | Threading primitive used by tools for long-running operations | Concurrency | Tools run logic in `BackgroundWorker_DoWork` |
